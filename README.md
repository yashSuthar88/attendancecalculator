**[attendancecalculator.me](https://attendancecalculator.me/)** is a free, fast, and accurate attendance calculation and prediction tool designed specifically for students. It helps you track your attendance, plan holidays, and ensure you never fall below your target percentage.

Built with a stunning, modern **glassmorphism** design aesthetic, it offers a fast, clean, and intuitive user experience entirely in the browser. 

---

## ✨ Features

### 📊 1. Attendance Calculator
Instantly calculate your current attendance percentage. 
* Find out exactly how many classes you can afford to skip.
* Discover how many consecutive classes you need to attend to reach your target percentage.
* Fast, accurate, and always up-to-date.

### 📅 2. Attendance Predictor
Take the guesswork out of your schedule.
* Enter your weekly timetable.
* Select upcoming public holidays and granular "week off" settings (e.g., odd/even Saturdays, Sundays off).
* The prediction engine simulates every day forward to pinpoint the **exact date** you will reach your target attendance.

### ✈️ 3. Holiday Planner
Plan your breaks with zero surprises.
* Pick your trip's start and end dates.
* Instantly see how many classes you'll miss and exactly how much your percentage will drop.

### 📉 4. Absence Impact Calculator
Quickly see the consequences of skipping upcoming classes.
* Know exactly how much your percentage will drop before you decide to skip.
* Stay informed and stay in the safe zone.

---

## 🛠️ Tech Stack & Architecture

* **HTML5:** Semantic architecture with modern tags for SEO and accessibility.
* **Vanilla CSS3:** Custom-built styling utilizing CSS Variables, Flexbox, CSS Grid, and sophisticated Glassmorphism UI tokens. Fully responsive across all devices with targeted dark/light aesthetic features.
* **Vanilla Web JavaScript (ES6+):** Complete logic handled on the client side without the overhead of heavy frameworks. Manages local state, DOM manipulations, and predictive mathematical array simulations.

## 🚀 Getting Started (Run Locally)

This project runs entirely on the client side. No build steps, complex installations, or backend setups are required!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/attendancecalculator.me.git
   ```
2. **Open the project:**
   Simply open the folder and double-click `index.html` to run the website locally in any modern web browser.
